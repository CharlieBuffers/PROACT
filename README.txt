PROACT branded site
===================

This is a static demo website intended for test/demo use only.

To deploy on Netlify:
1. Unzip PROACT_branded_site.zip.
2. Drag the PROACT_branded_site folder into Netlify's Production deploys area.
3. Netlify will replace the currently published site with this version.

Included:
- PROACT logo and branding
- Consistent PROACT spelling
- Report categories for hospitality
- Dashboard preview
- Risk Library preview
- Corrective Actions preview
- PROACT Pattern Alert
- Demo report form

Important:
This build is visual/demo only. It does not store reports or send emails.
Use test data only.
